# repertoire-efficiency-analysis
Evaluating Repertoire Efficiency (Multi-Platform Conversion Analysis 2024)

Executive Summary
An end-to-end data analysis evaluating multi-platform streaming performance across 4600 tracks. This project analyses conversion dynamics between short-form video discovery (TikTok) and long-term streaming retention (Spotify, Apple Music, Pandora, Deezer) to identify performance friction and catalog conversion tiers.

---

Key Analytical Insights

1. Friction Metrics
Identified divergence between high-virality and long-term streaming conversion
2. Conversion Tiers
Categorised tracks into clear efficiency tiers using percentile calculations
